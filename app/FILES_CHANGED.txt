## 🔑 KEY TECHNICAL CHANGES

### Schema Level:
- Jobs table: +5 fields (company_name, contact_info, location, type, updated_at)
- Jobs table: vendor_id jadi optional (NULL)
- Jobs table: +1 auto-update trigger
- NEW: media_jobs table (for job media, not vendor media)

### Code Level (Admin):
- fetchJobs: Media dari media_jobs bukan media table
- handleSave: Insert ke media_jobs dengan job_id
- handleDelete: Explicit delete cascade
- Error handling: Try/catch semua operations

### Code Level (User):
- getJobs: Simple query tanpa joins
- Display: company_name langsung, bukan vendor relation
- force-dynamic: Enabled untuk fresh data

### Data Flow:
```
BEFORE:
Admin Form → Jobs Insert (fail) → No data in DB → User page empty

AFTER:
Admin Form → Jobs Insert (success) 
         → Media Insert to media_jobs (success)
         → Auto-refresh state list
         → User page query jobs table
         → Data appears otomatis (force-dynamic)
```
